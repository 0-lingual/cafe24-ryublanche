## 프로젝트 아키텍처

```
main.py                  # 진입점
src/
  api/
    app.py               # FastAPI 앱
                         #   GET  /
                         #   POST /api/analyze          — 대표 이미지 AI 분석
                         #   GET  /api/categories       — 카테고리 목록
                         #   POST /api/body-images      — 본문 이미지 업로드 (860px 리사이징)
                         #   POST /api/analyze-body     — 본문 이미지 → 카피 텍스트 AI 생성
                         #   POST /api/products         — 상품 등록 (이미지+옵션+본문)
                         #   GET  /api/products         — 상품 목록
    processor.py         # 이미지 처리
                         #   process_product_images()  — 4종 규격 정방형 크롭 + base64
                         #   process_body_image()      — 860px 리사이징 + base64
    static/index.html    # 어드민 UI
  ai/
    analyzer.py          # Claude Vision 분석
                         #   analyze_image()           — 대표 이미지 → 상품 정보 JSON
                         #   analyze_body_images()     — 본문 이미지 1~4장 → 카피 텍스트 JSON
                         #     BODY_SYSTEM_PROMPT: STEP1(시각특징 추출) → STEP2(특징 기반 텍스트 작성)
  cafe24/
    client.py            # 카페24 REST API 클라이언트
    auth.py              # OAuth 인증
    token_manager.py     # 토큰 자동 갱신
    callback_server.py   # 초기 인증용 콜백 서버 (포트 8080)
uploads/                 # 업로드된 이미지 저장
.token.json              # 토큰 (gitignore)
.env                     # 환경변수
```

### 핵심 플로우
1. 대표 이미지 업로드 → `/api/analyze` → Claude Vision → 상품명/가격/태그 등 자동 입력
2. 본문 이미지 1~4 업로드 → "✨ 본문 텍스트 자동 생성" → `/api/analyze-body` → 카피 텍스트 자동 입력
3. 본문 이미지 5~15 추가 (선택)
4. "카페24에 등록" → `/api/products` → 상품 생성 + 대표 이미지 업로드 + 본문 HTML 삽입
5. "쇼핑몰에서 보기" 클릭 → 상품 페이지에서 본문 이미지+텍스트 확인
